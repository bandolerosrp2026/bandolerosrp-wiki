# Bienvenido a BandolerosRP

BandolerosRP es un servidor de **rol serio** de GTA V en español. Aquí tienes todo lo que necesitas saber para
jugar: cómo crear tu personaje, qué teclas usar y cómo funciona cada sistema de la ciudad (banco, coches,
llaves, gasolineras, talleres, trabajos, ropa, tatuajes…).

{% hint style="info" %}
**¿Primera vez?** Empieza por [Tu primer día](primeros-pasos/tu-primer-dia.md) y
[Controles y teclas](primeros-pasos/controles.md). Con eso ya puedes moverte por la ciudad.
{% endhint %}

{% hint style="success" %}
**¿Buscas algo concreto?** Entra en [¿Qué quieres hacer?](que-quieres-hacer.md): eliges lo que quieres hacer y te
lleva a su página. También puedes usar el **buscador** de arriba.
{% endhint %}

## Conectarse

En FiveM pulsa **F8** y escribe:

```
connect 134.255.219.130:30130
```

## Lo más importante en una línea

| Quiero… | Cómo |
|---|---|
| Interactuar con algo (NPC, coche, cajero, surtidor…) | Mantén **Alt izquierdo** y elige la opción |
| Abrir el inventario | **TAB** |
| Escribir en el chat | **T** |
| Abrir o cerrar mi coche | **U** |
| Encender o apagar el motor | **G** |
| Ver mis llaves | **F5** |
| Menú de mi trabajo | **F6** |
| Pedir ayuda a un administrador | `/report tu mensaje` |
