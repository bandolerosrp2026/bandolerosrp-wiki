# Todos los comandos

{% hint style="info" %}
Cada cosa tiene **un solo comando**: desde el 21-11-2026 ya no hay dos nombres para lo mismo (por ejemplo,
para susurrar solo vale `/s`). Usa los de esta lista.
{% endhint %}

## Rol y chat

| Comando | Qué hace |
|---|---|
| `/me acción` | Acción de tu personaje (20 m) |
| `/do descripción` | Describir el entorno (20 m) |
| `/intentar acción` | Intento con resultado al azar: Éxito o Fallo (20 m) |
| `/dado [caras]` | Tirar un dado de 2 a 100 caras (20 m) |
| `/s texto` | Susurrar (3 m) |
| `/g texto` | Gritar (45 m) |
| `/ooc texto` | Fuera de rol (20 m) |
| `/twt texto` | Twitter (toda la ciudad) |
| `/anuncio texto` | Anuncio público |
| `/entorno qué ocurre` | Aviso de entorno a la policía: anónimo y con zona aproximada |
| `/condena` | Ver cuánto te queda de condena |
| `/soltarse` | Intentar soltarte de las esposas o bridas (también tecla J) |
| `/mdt` | Policía: abrir la tableta ([Policía](../trabajos/policia.md)) |
| `/k9` | Policía: sacar o guardar el perro |
| `/auxilio [qué ha pasado]` | Pedir una ambulancia: avisa a los médicos de servicio ([Heridas y hospital](../primeros-pasos/muerte.md)) |
| `/misheridas` | Ver tus heridas, constantes y sangre |
| `/tabletaems` | EMS: abrir la tableta ([EMS](../trabajos/ems.md)) |
| `/pesca` | Abrir tu cuaderno de pesca: misiones, logros, torneo y guía de peces ([Pesca](../trabajos/pesca.md)) |
| `/micamping` | Ver todo lo que tienes colocado de camping, con distancia y GPS ([Camping](../trabajos/camping.md)) |
| `/suelo` | Tirarte al suelo; otra vez (o **X**) para levantarte. Puedes ponerle tecla en Asignación de teclas |
| `/cargar` | Cargar a hombros a quien tengas al lado: si está consciente tiene que aceptar; si está abatido, no. Otra vez (o **X**) para soltarlo. También en el menú de interacción («Cargar a hombros») |
| `/id` | Tu número de jugador |
| `/ayuda` | Ayuda del chat |
| `/limpiar` | Borrar tu chat |
| `/ocultarchat` | Modo del chat (tecla L) |
| `/report texto` | Hablar con el staff |

## Dinero

| Comando | Qué hace |
|---|---|
| `/darefectivo id cantidad` | Dar efectivo a alguien cercano |
| `/facturas` | Tus facturas y multas |

## Vehículos

| Comando | Qué hace |
|---|---|
| `/llaves` | Llavero (tecla F5) |
| `/darllaves [id]` | Dar una copia de la llave del vehículo cercano |
| `/taller` | Tus órdenes, presupuestos y facturas del taller |
| `/facturataller` | Volver a abrir la factura que te acaba de mandar el mecánico |
| `/terminarprueba` | Terminar antes la prueba de conducción de un concesionario |

## Trabajo

| Comando | Qué hace |
|---|---|
| `/menutrabajo` | Menú de trabajo (tecla F6) |
| `/trabajos` | Tus trabajos (hasta 3): cambiar el activo o dejar uno |
| `/tabletmecanico` | Tableta de mecánico (mecánicos de servicio) |

## Personaje e interfaz

| Comando | Qué hace |
|---|---|
| `/hud` | Mostrar u ocultar el HUD |
| `/reloadskin` | Recargar tu apariencia |
| `/ajustestarget` | Ajustes del menú de interacción |
| `/sonidos` | Volumen de los sonidos de los elevadores |
