# Hablar con el staff (/report)

Si tienes un problema (un fallo, alguien rompe las normas, te has quedado atascado, has perdido algo…), escribe:

```
/report lo que te pasa
```

## Qué pasa después

1. Tu reporte llega al panel del staff.
2. Un miembro del staff lo **coge** y te **contesta**: lo verás en pantalla y en el chat.
3. Si tienes un reporte abierto y vuelves a escribir `/report`, se **añade** a la misma conversación.
4. Cuando está resuelto, el staff lo cierra.

## Consejos para que te ayuden antes

- Explica **qué** ha pasado, **dónde** y **con quién** (su ID si lo sabes: `/id` muestra el tuyo).
- Si es una queja de rol (RDM, VDM, metagaming…), di cuándo pasó.
- Un reporte por problema. No repitas el mismo varias veces.
- Graba o haz capturas si puedes.

{% hint style="info" %}
El staff puede tardar si está atendiendo otros reportes. No hace falta escribirle por privado.
{% endhint %}
