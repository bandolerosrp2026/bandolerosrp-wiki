# Chat y comandos de rol

## Usar el chat

- **T** abre el chat. **Intro** envía, **Esc** cierra.
- **Tab** completa el comando; **↑ / ↓** recorren lo que has escrito antes.
- **L** cambia el modo: *automático* (se ve unos segundos tras cada mensaje) → *siempre visible* → *oculto*.
- Los mensajes se borran solos a los 2 minutos (mientras tienes el chat abierto no se borra nada).
- `/limpiar` borra tu chat.

Cada tipo de mensaje sale en una tarjeta con su icono y color, para distinguir de un vistazo el rol (IC) de lo
que no es rol (OOC).

## Comandos de rol

| Comando | Quién lo ve | Para qué |
|---|---|---|
| `/me acción` | Quien esté a 20 m | Describir lo que hace tu personaje. *Ej.: `/me saca la cartera del bolsillo`* |
| `/do descripción` | 20 m | Describir el entorno o algo que se ve. *Ej.: `/do Se ve una mancha de sangre en la camisa`* |
| `/intentar acción` | 20 m | Intentar algo con resultado al azar (50 %): sale **Éxito** o **Fallo** |
| `/dado [caras]` | 20 m | Tirar un dado (de 2 a 100 caras; 6 si no pones nada) |
| `/s texto` | 3 m | Susurrar |
| `/g texto` | 45 m | Gritar |
| `/twt texto` | Toda la ciudad | Publicar en Twitter con tu `@Nombre_Apellido` (cada 15 s) |
| `/anuncio texto` | Toda la ciudad | Anuncio público (cada 60 s) |
| `/112 motivo` | Policía y emergencias de servicio | Llamada de emergencia; incluye la calle donde estás (cada 30 s) |

## Fuera de rol (OOC)

- `/ooc texto` (o escribir **sin «/»**): mensaje fuera de rol para quien esté a 20 m. Sale con tu
  nombre de FiveM, no el de tu personaje.

{% hint style="warning" %}
El OOC es para lo imprescindible (dudas técnicas, avisar de un fallo). No uses el OOC para dar información
que tu personaje no sabe (metagaming).
{% endhint %}

## Normas del chat

- Hay control anti-spam: no puedes mandar mensajes muy seguidos ni repetir el mismo.
- El staff puede silenciarte el chat durante un tiempo; el silencio se mantiene aunque reconectes.
