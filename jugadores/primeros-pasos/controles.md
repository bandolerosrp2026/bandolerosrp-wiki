# Controles y teclas

Estas son las teclas **por defecto**. Todas las acciones de nuestros sistemas se pueden cambiar a tu gusto, y
muchas que no traen tecla puedes ponértela tú.

{% hint style="info" %}
**Cómo cambiar una tecla:** ESC → **Ajustes** → **Asignación de teclas** → **FiveM**. Busca la acción por su nombre
(«Chat: …», «Llaves: …», «Mecánico: …», «Policía: …»…), pulsa en ella y aprieta la tecla nueva. Se guarda en tu
ordenador y vale para siempre.
{% endhint %}

## General

| Tecla | Qué hace |
|---|---|
| **Alt izquierdo** (mantener) | Menú de interacción: NPC, vehículos, cajeros, surtidores, jugadores… Ver [Interactuar](interactuar.md) |
| **TAB** | Abrir el inventario |
| **K** | Abrir el inventario secundario (guantera o maletero del vehículo cercano) |
| **F1** | Mostrar u ocultar la barra rápida del inventario |
| **1 – 5** | Usar el objeto de esa casilla de la barra rápida |
| **R** | Recargar el arma |
| **ESC** | Menú de pausa (mapa, ajustes, salir) |
| **P** | Mapa |

## Personaje

| Tecla | Qué hace |
|---|---|
| **Control izquierdo** | Agacharse o levantarse (a pie) |
| **B** | Señalar con el dedo hacia donde miras (otra vez para dejarlo) |
| **X** | Levantar o bajar las manos. Si estás en el suelo, señalando, cargando a alguien o te llevan a hombros, la X lo cancela primero |
| *(sin tecla)* | Tirarse al suelo / levantarse: lo mismo que `/suelo` («Tirarse al suelo…») |
| *(sin tecla)* | Cargar a hombros a quien tengas al lado o soltarlo: lo mismo que `/cargar` («Cargar a hombros…») |

## Chat y voz

| Tecla | Qué hace |
|---|---|
| **T** | Abrir el chat |
| **L** | Modo del chat: automático → siempre visible → oculto |
| **N** | Hablar (pulsar para hablar, según tus ajustes de voz de GTA) |
| **º** (a la izquierda del 1) | Cambiar el alcance de la voz: Susurrar → Normal → Gritar |

## Vehículos

| Tecla | Qué hace |
|---|---|
| **U** | Abrir o cerrar el vehículo con llave más cercano |
| **G** | Al volante: encender o apagar el motor. A pie: arrancar tu coche a distancia |
| **S** | También arranca el motor (igual que acelerar) |
| **H** | Buscar las llaves dentro de un coche ajeno (sentado al volante) |
| **W** | Volver a intentar el puente en un coche de la ciudad sin llave (sentado al volante) |
| **W A S D** + **ratón** | Minijuego del puente y de forzar cerraduras: WASD el semicírculo izquierdo, ratón el derecho (**Esc** para dejarlo) |
| **F5** | Llavero (todas tus llaves y el mando a distancia) |

## Trabajo

| Tecla | Qué hace |
|---|---|
| **F6** | Menú de trabajo: entrar o salir de servicio, gestión (jefes), facturas, colocar objetos |
| **E** | Mecánicos: trabajar en el paso señalado si el menú de interacción no llega |
| **X** | Mecánicos: cancelar el trabajo en curso |
| **Mayús izquierdo** | Nitro (solo vehículos que lo tengan instalado) |

## Caza

| Tecla | Qué hace |
|---|---|
| **G** | Soltar la pieza que llevas al hombro («Caza: soltar la pieza…») |
| *(sin tecla)* | Buscar rastros de animales: asígnala en Ajustes → Asignación de teclas → FiveM («Caza: buscar rastros…») |
| **Rueda · clic · clic derecho** | Con los prismáticos: zoom, marcar el animal en el mapa y guardarlos |

Todo en [Caza](../trabajos/caza.md).

## Paintball

| Tecla | Qué hace |
|---|---|
| **TAB** (mantener) | Ver el marcador de la partida |
| **Clic central** | Marcar para tu equipo al rival al que apuntas |
| **← · →** | Como espectador: cambiar de jugador |
| *(sin tecla)* | Abrir la clasificación y tu perfil («Paintball: abrir clasificación y perfil…») |

Todo en [Paintball](paintball.md).

## Policía

| Tecla | Qué hace |
|---|---|
| **← / →** | Pasar de un aviso a otro en la pantalla de avisos |
| **↑** | Aceptar el aviso que se ve |
| **↓** | Ampliar o reducir el aviso |
| **F7** | Radar del coche patrulla (en el helicóptero: cámara) |
| **F9** | Fijar la lectura del radar |
| **H** | Placaje (corriendo detrás de alguien) |

## Calle y crimen

| Tecla | Qué hace |
|---|---|
| **X** | Levantar las manos (o cancelar la animación en curso) |
| **J** | Intentar soltarte si estás esposado o con bridas |
| **E** | Atracar a un ciudadano rendido: registrarle (mientras le apuntas) |
| **G** | Atracar a un ciudadano rendido: que te siga |
| **G** | Soltar al rehén que llevas de escudo humano |

## Sin tecla: ponles la que quieras

Estas acciones no traen tecla para no pisar otras, pero están en **Asignación de teclas → FiveM** para que les
pongas la tuya:

| Acción | Qué hace |
|---|---|
| HUD: mostrar u ocultar | Lo mismo que `/hud` |
| Chat: limpiar · ver mi ID · tirar un dado | Lo mismo que `/limpiar`, `/id` y `/dado` |
| Trabajos: mis facturas y multas | Lo mismo que `/facturas` |
| Llaves: dar una copia al jugador más cercano | Lo mismo que `/darllaves` |
| Taller (cliente): mis presupuestos, facturas y vehículo | Lo mismo que `/taller` |
| Mecánico: abrir la tableta | Solo mecánicos (de servicio) |
| Policía: tableta · botón del pánico · radio | Solo policías |
| Prisión: ver la condena que me queda | Lo mismo que `/condena` |
| Concesionario: terminar la prueba de conducción | Durante una prueba |

| `/id` | Ver tu número de jugador |
| `/llaves` | Abrir el llavero |
| `/facturas` | Ver y pagar tus facturas y multas |
| `/taller` | Tus presupuestos y facturas del taller |

| `/ajustestarget` | Cambiar el aspecto y sonido del menú de interacción |
| `/sonidos` | Volumen de los sonidos de los elevadores del taller |
| `/report texto` | Pedir ayuda al staff |
| `/ayuda` | Lista de comandos del chat |

Lista completa en [Todos los comandos](../ayuda/comandos.md).
