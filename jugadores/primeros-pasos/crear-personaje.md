# Crear tu personaje

El creador de personaje de BandolerosRP se abre la primera vez que entras. Tu personaje **no se crea** hasta que
pulsas **«Crear personaje»** al final: si sales antes, no se guarda nada.

{% hint style="warning" %}
Solo puedes tener **un personaje**. Si necesitas cambiar algo importante después (nombre, sexo…), tendrás que
pedirlo al staff con `/report`.
{% endhint %}

## Los pasos

| Paso | Qué eliges |
|---|---|
| **Identidad** | Nombre, apellidos, fecha de nacimiento, sexo y nacionalidad |
| **Genética** | Padre y madre (con sus retratos), parecido y tono de piel |
| **Rasgos** | Forma de la cara: nariz, cejas, pómulos, mandíbula, mentón, ojos, labios… |
| **Cabello** | Peinado, colores, cejas y vello facial |
| **Detalles** | Maquillaje, imperfecciones, envejecimiento, pecas, color de ojos… |
| **Ropa inicial** | Tu primera ropa, **gratis**, elegida entre la ropa del servidor |
| **Finalizar** | Repaso y «Crear personaje» |

Puedes girar al personaje y la cámara se acerca sola a la zona que estás editando.

## Normas del nombre

El servidor comprueba tu identidad antes de crear el personaje:

- **Nombre:** de 2 a 24 letras, como mucho 2 palabras.
- **Apellidos:** de 2 a 32 letras, como mucho 3 palabras (valen «García López» o «de la Vega»).
- **Edad:** entre 18 y 90 años.
- **No se admiten** nombres de famosos, nombres de broma ni palabras como «admin», «staff», «policía» o el nombre
  del servidor.
- No puede haber dos personajes con el mismo nombre completo.

{% hint style="info" %}
Es un servidor de rol serio: usa un nombre creíble. Los nombres que rompan el rol se pueden cambiar o
sancionar.
{% endhint %}

## Después de crearlo

- Tu apariencia se guarda y la verás igual cada vez que entres.
- Para cambiar de ropa: [tiendas de ropa](../personaje/ropa.md).
- Para cambiar de peinado o maquillaje: [barberías](../personaje/barberias.md).
- Para tatuarte: [estudios de tatuajes](../personaje/tatuajes.md).
