# Interactuar con el mundo

Casi todo en BandolerosRP se hace con el **menú de interacción** (Bandoleros Target). No hay carteles de
«Pulsa E» repartidos por la ciudad: miras la cosa y eliges qué hacer.

## Cómo se usa

1. **Mantén pulsado Alt izquierdo.** Aparece un punto de mira.
2. Apunta a lo que quieras: un NPC, un vehículo, otro jugador, un cajero, un surtidor, una puerta…
3. Si hay opciones, se abre un menú con un título (por ejemplo «Vehículo · Sultan · 66KBJ304»).
4. Haz **clic izquierdo** en la opción. También puedes moverte con las flechas y pulsar Intro.
5. Suelta Alt para cerrarlo.

{% hint style="info" %}
Si no sale ninguna opción, puede que estés demasiado lejos, que no tengas el trabajo o el objeto necesario, o
que no estés de servicio. Las opciones con **candado** se ven pero aún no las puedes usar.
{% endhint %}

## Ejemplos de lo que puedes hacer

| Apuntas a… | Opciones típicas |
|---|---|
| Banquero (NPC) | Gestionar mis cuentas |
| Cajero automático | Usar el cajero |
| Surtidor | Repostar, coger la manguera |
| Tu vehículo | Abrir / Cerrar, Llaves, Guardar vehículo, Maletero |
| Otro jugador | Dar efectivo y, según tu trabajo, acciones como facturar o cachear |
| Dependienta de ropa | Abrir la tienda |
| Vehículo averiado (mecánico) | Los pasos de la reparación |

## Ajustes del menú

Escribe `/ajustestarget` para cambiar:

- **Modo**: *Premium* (por defecto), *Compacto* (más pequeño) o *Rendimiento* (sin efectos, para equipos
  modestos).
- **Sonidos** y su volumen.
- **Tamaño** del menú (80 % – 130 %).

Se guarda en tu ordenador.
