# Manual del staff de BandolerosRP

Manual **interno** del equipo: rangos, panel de staff, moderación y cómo se administra cada sistema del servidor.

{% hint style="danger" %}
**Confidencial.** No compartas este manual con jugadores. Incluye comandos de administración, cómo funcionan
las detecciones de robo y procedimientos internos.
{% endhint %}

## Lo básico

| Quiero… | Cómo |
|---|---|
| Abrir el panel de staff | **INSERT** o `/menustaff` (`/admin`) |
| Ponerme de servicio | Panel → Inicio / Equipo → Servicio |
| Atender un reporte | Panel → Reportes → Coger → Responder |
| Hablar con el equipo | `/staff texto` (o `/st`) o el chat del panel |
| Mensaje privado a un jugador | `/mp id texto` |
| Revivir a alguien | Panel → ficha del jugador → Revivir |

## Normas de uso

1. **Todo queda registrado**: cada acción del panel, cada comando y cada herramienta van al registro y a Discord,
   con quién lo hizo y a quién.
2. Usa las herramientas **solo para moderar**. Nada de noclip, invisible o teletransportes para sacar ventaja en
   rol.
3. Antes de sancionar, **escucha a las dos partes** y deja constancia en el reporte.
4. No se puede actuar sobre alguien de tu mismo rango o superior; si hace falta, avisa a un rango superior.
5. Las acciones *troll* son solo para administración y para situaciones justificadas (y quedan en Discord en una
   categoría propia).

## Secciones

* **Empezar**: rangos y permisos, el panel, las herramientas.
* **Moderación**: reportes, sanciones, registro y Discord.
* **Sistemas**: cómo administrar cada sistema (garajes, llaves, banco, combustible, trabajos, talleres, ropa,
  tatuajes, chat, personajes).
* **Servidor**: operación diaria, procedimientos de recuperación y estado de los sistemas.
