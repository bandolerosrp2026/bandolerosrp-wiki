# Herramientas

Panel → **Herramientas**. Cada una indica el rango mínimo ([Rangos](rangos.md)).

| Herramienta | Qué hace | Rango |
|---|---|---|
| **Noclip** | Volar atravesando todo. **W A S D** moverse, **ESPACIO** sube, **CTRL** baja, **MAYÚS** rápido, **ALT** lento, **rueda** cambia la velocidad | Moderador |
| Invisible | Nadie te ve | Moderador |
| Nombres e ID | Nombre e ID sobre la cabeza de cada jugador | Moderador |
| Jugadores en el mapa | Posiciones de todos (según el servidor) | Moderador |
| Visión nocturna / térmica | | Moderador |

| Coordenadas | Cuadro en pantalla; copiar vec2 / vec3 / vec4 / orientación | Soporte |

## Atajos de teclado

Todas las herramientas se pueden poner en una tecla. Vienen **sin tecla** para no chocar con nada:
ESC → Ajustes → Asignación de teclas → FiveM → las que empiezan por **«Staff:»**.

Solo aparecen para el staff y solo las de tu rango. Cada pulsación pasa por el servidor (permiso y registro) y
avisa «Noclip: activado / desactivado».

{% hint style="warning" %}
Las herramientas quedan en el registro y en Discord. Úsalas para moderar, no para jugar.
{% endhint %}
